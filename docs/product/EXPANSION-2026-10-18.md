# SmartGate — قرارات التوسعة المعتمدة، 18 أكتوبر 2026

هذه قرارات A اعتمدها المستخدم صراحة في المحادثة. اعتماد النطاق لا يعني اكتمال التنفيذ.

| القرار | النطاق المعتمد | حالة التنفيذ عند الاعتماد |
|---|---|---|
| A13 | حفظ كود MVP في مستودع GitHub الحالي | دُفع الإصدار الأساسي في `2f78e00` |
| A14 | واجهة لإدارة الشركات والحسابات والسائقين والشاحنات وإسناد البوابات، دون تسجيل عام | مطلوب؛ يتطلب ترحيل صلاحيات وإدارة حسابات موثوقًا |
| A15 | تحديثات لحظية وإشعارات خارجية؛ البريد الإلكتروني أول قناة، عبر خطة Resend المجانية مباشرة حسب موافقة المستخدم | شروط Marketplace مقبولة؛ لم ينشأ مورد بريد. لا يملك المستخدم نطاقًا حاليًا |
| A16 | الخرائط وقراءة QR بكاميرا المستخدم | مطلوب؛ لا يغيّر ذلك حالة محاكاة الأجهزة الميدانية |
| A17 | العربية والإنجليزية والهندية والأوردية والبنغالية والمالايالامية والتاميلية والنيبالية | مطلوب؛ لا تُعلن لغة مكتملة قبل ترجمة جميع واجهاتها واختبارها |

تظل حدود A01–A12 وFR01–FR15 نافذة: الدخول فقط، والتحقق والفتح والعبور أحداث مستقلة. فشل البريد لا يلغي عبورًا محفوظًا. لا ترسل رسائل فعلية إلى عناوين العرض `*.test`.

تحديث A15 بموافقة المستخدم: لا يُنشأ اشتراك Marketplace مدفوع ولا يُشترى نطاق. بدون نطاق موثق، يتيح Resend الإرسال التجريبي من `onboarding@resend.dev` إلى بريد صاحب حساب Resend فقط؛ لا يمثل ذلك تفعيل بريد الشركات والسائقين. ينتظر التكامل إنشاء الحساب المجاني وإعداد مفتاح خادم خاص. إرسال رسالة فعلية يتطلب تحديد المستلم والإذن بإرسالها. يظل إرسال المستخدمين الآخرين متوقفًا حتى توثيق نطاق لاحقًا.

افتراض P قابل للعكس للخرائط: لا توجد إحداثيات بوابات معتمدة حاليًا. تعرض الواجهة غياب الإعداد وتسمح للمستخدم بعرض موقعه بإذنه، دون اختلاق موقع ميناء أو مسار أو مدة وصول حقيقية.

يتطلب A14 سلطة إدارة مستقلة عن حساب المحاكاة. لا يمنح `demo_admin` سلطة إدارة حسابات حقيقية ضمنيًا، ولا يسمح للعميل باختيار دوره أو شركته من بياناته الذاتية. يلزم اختبار منع التصعيد وعزل الشركات قبل تفعيل الإدارة.

## تقدم التنفيذ

- A13: حُفظ MVP والتوسعة وإصلاح QR في GitHub على `main`، مع نشر Vercel الآلي.
- A14: واجهة الإضافة وإسناد البوابات وسجل التدقيق منفذة، وSQL مختبر محليًا. التفعيل السحابي واختبار Auth Admin ينتظران اتصال إدارة Supabase ومفتاح الخادم وتفويض حساب موثوق.
- A15: التحديث الدوري الاحتياطي يعمل واختُبر بين حسابين على الإنتاج. اشتراك Realtime وترحيل النشر جاهزان، دون ادعاء تطبيق الترحيل. تجهيز البريد متوقف قبل التكامل على خطوة حساب Resend.
- A16: قراءة كاميرا QR ومعالجتها محليًا، وعرض الموقع والخريطة الخارجية منفذة. إحداثيات البوابات قابلة للتهيئة في ترحيل الإدارة المنتظر؛ لا مسارات أو ETA ميدانية.
- A17: ترجمت مفاتيح الواجهة كاملة للغات الثماني واختبرت المسارات والاتجاه والتجاوب والخطوط. لم يُجر تدقيق تحريري بشري متخصص للترجمات الجديدة.
