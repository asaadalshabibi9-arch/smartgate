# SmartGate

نموذج هاكاثون لتنظيم دخول الشاحنات إلى الميناء. ينتهي النطاق عند تأكيد العبور وتوثيق الدخول، ولا يشمل الخروج أو العمليات داخل الميناء.

## التشغيل المحلي
يتطلب Node.js 24 وnpm.

~~~sh
npm ci
npm run dev
~~~

افتح http://localhost:3000.

## ربط Supabase

انسخ `.env.example` إلى `.env.local` ثم استبدل قيمة
`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` بالمفتاح العام من لوحة Supabase.
ملف `.env.local` مستثنى من Git ولا ينبغي رفعه إلى المستودع.

طبقتا الاتصال موجودتان في `src/lib/supabase/client.ts` للمتصفح و
`src/lib/supabase/server.ts` للخادم. مخطط قاعدة البيانات مطبق على مشروع
Supabase ومحفوظ كترحيلات قابلة للتتبع في Git.

بعد تشغيل التطبيق، يفحص المسار `/api/health/supabase` الاتصال دون كشف المفتاح
أو بيانات المشروع. يعيد `connected: true` عند نجاح الاتصال.

## الفحوص
~~~sh
npm run lint
npm run typecheck
npm run build
~~~

تشغّل GitHub Actions هذه الفحوص عند كل push وpull request. نجاح الفحوص لا يمنع الدمج تلقائيًا؛ يلزم إعداد قواعد حماية الفرع عند الحاجة.

## حالة التنفيذ
- أساس Next.js وTypeScript وTailwind CSS وصفحة بداية عربية.
- إعداد فحوص GitHub Actions.
- جُهّز اتصال Supabase واختُبر عبر مسار فحص الصحة.
- طُبق مخطط Supabase الأولي من `supabase/migrations` مع سياسات RLS.
- بيانات البوابات التجريبية محفوظة في `supabase/seed.sql`.
- أنواع قاعدة البيانات مولدة في `src/types/database.ts` ومستخدمة في العملاء.
- وظائف المنتج والنشر على Vercel لم تُنفذ بعد.
- لا تتضمن هذه النسخة اتصالًا بميناء أو أجهزة ميدانية.

لا ترفع ملفات .env.local أو كلمات المرور أو مفاتيح الخدمات إلى GitHub.

## قاعدة البيانات

يضم الترحيل الأول الشركات والملفات الشخصية والأدوار والشاحنات والبوابات
والرحلات وسجل الأحداث والإشعارات. حدث `crossing_confirmed` وحده يكمل الرحلة
ويثبت وقت العبور؛ فتح الحاجز أو نجاح التحقق لا يكملانها.

سجل الترحيلات المحلي مطابق لسجل المشروع السحابي. يتطلب تشغيل Supabase محليًا
Docker، بينما تتم مراجعة المشروع السحابي عبر اتصال MCP المقيّد بالمشروع.


## تنبيه اعتماديات التطوير

فحص npm audit بتاريخ 16 أكتوبر 2026 أظهر خمسة تنبيهات high في سلسلة ESLint بسبب braces (GHSA-vfj7-8cjw-p6xm). لا يوجد إصدار مصحح وفق التنبيه المنشور. الحزم المعنية أدوات تطوير؛ لم نطبق اقتراح الرجوع إلى إصدار قديم من eslint-config-next بالقوة. تراجع الحالة عند تحديث الاعتماديات.
